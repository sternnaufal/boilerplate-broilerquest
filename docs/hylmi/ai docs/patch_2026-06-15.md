
## Update - 15 Juni 2026

### 1. Panel MemoryMatch disamakan dengan Jigsaw
- **File:** `Assets/Script/Minigame/MemoryMatchController.cs`
- **Tujuan:** Panel MemoryMatch memiliki struktur UI yang konsisten dengan Jigsaw (ukuran panel, tata letak title/timer/grid, canvas config)
- **Perubahan:**
  - `additionalShaderChannels` ditambahkan ke canvas (TexCoord1, Normal, Tangent)
  - Canvas rect stretch pakai `StretchToParent()` helper (sama seperti Jigsaw)
  - Panel size 450×550 → **500×600**
  - TitleText pos/size/font: (0,240) 400×40 26pt → **(0,270) 500×50 28pt**
  - TimerText pos/size/font: (0,195) 120×40 32pt → **(0,220) 160×48 34pt**
  - ErrorText pos: (0,0) → (0,130) — di atas grid
  - GridContainer pos: (0,-30) → **(0,-35)**
  - Timer warning threshold: hardcoded `10f` → `GameConstants.MemoryMatch.WarningThreshold`
  - `StretchToParent()` helper method ditambahkan

- **File:** `Assets/Script/Core/GameConstants.cs`
  - `WarningThreshold = 10f` ditambahkan ke `MemoryMatch` constants

### 2. Floating Feedback Text (teks melayang)
- **File baru:** `Assets/Script/UI/FloatingFeedback.cs`
- **Deskripsi:** Menampilkan teks "+X Coin" / "-X Pakan" yang melayang naik dan fade di samping counter
- **Cara kerja:**
  - Auto-create `FloatingFeedbackCanvas` (sortingOrder 700) saat pertama dipanggil
  - Teks spawn sebagai `TextMeshProUGUI`, lifeTime 1.2 detik, floatSpeed 60px/detik
  - 4 static methods: `ShowCoin()`, `ShowFeed()`, `ShowText()`
  - Warna: coin kuning (#FFFCE6B3), feed biru muda (#B3D9FF)

### 3. Camera Shake
- **File baru:** `Assets/Script/UI/CameraShake.cs`
- **Deskripsi:** Getaran kamera sebagai feedback gagal/sukses
- **Cara kerja:**
  - Auto-create saat pertama dipanggil
  - Random offset dengan decay (intensity menurun seiring waktu)
  - Default: duration 0.3s, intensity 0.15
  - Minigame sukses: 0.15s / 0.05 (getaran halus)
  - Minigame gagal: default (getaran kuat)

### 4. Health Check Result Overlay
- **File baru:** `Assets/Script/UI/HealthCheckResultOverlay.cs`
- **Deskripsi:** Overlay "Berhasil!" (hijau) / "Gagal!" (merah) setelah minigame selesai
- **Struktur UI:**
  - `HealthResultCanvas` (ScreenSpaceOverlay, sortingOrder 600)
  - Backdrop: fullscreen hitam alpha 0.4
  - Panel: 400×200, hijau gelap (sama seperti panel minigame)
  - ResultText: fontSize 48, Bold
- **Integrasi:**
  - `CompleteWithSuccess` → `HealthCheckResultOverlay.ShowSuccess()` + `CameraShake.Trigger(0.15f, 0.05f)`
  - `CompleteWithFailure` → `CameraShake.Trigger()` + `HealthCheckResultOverlay.ShowFail()`

### 5. Animated Counter (animasi angka smooth)
- **File diubah:** `Assets/Script/UI/UIGlobalBinder.cs`
- **Deskripsi:** Angka coin/pakan di UI bertransisi secara smooth (lerp 0.3 detik) saat nilainya berubah
- **Perubahan:**
  - `UpdateCoinDisplay()` dan `UpdateFeedDisplay()` sekarang memulai coroutine `AnimateCoinText` / `AnimateFeedText`
  - Counter lerp dari nilai yang tampil ke nilai target dalam `counterAnimDuration` (default 0.3s)
  - Floating text dipicu setelah perubahan (tidak pada initial load — dicek via `coinInitialized` / `feedInitialized`)
  - `GetTextScreenPos()` helper untuk mendapatkan posisi screen dari TextMeshPro
